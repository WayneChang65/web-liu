功能說明

快捷鍵

  • 切換輸入法: Ctrl + p
  • 粗體: Ctrl + b
  • 斜體: Ctrl + i
  • 底線: Ctrl + u
  • 放大選取文字: Ctrl + ], Ctrl + Shift + >, 或 Ctrl + 0
  • 縮小選取文字: Ctrl + [, Ctrl + Shift + <, 或 Ctrl + 9

匯出功能

點擊「匯出」按鈕可以將編輯區的內容轉換為 Markdown 格式並下載。此功能會保留以下格式：

  • 粗體
  • 斜體
  • 底線 (以 HTML <u> 標籤保留)
  • 自訂字級大小 (以 HTML <span> 標籤保留)

暫存功能

  • 存入暫存: 點擊「存入暫存」按鈕可以手動將目前編輯區的內容儲存於瀏覽器中。
  • 讀回暫存: 點擊「讀回暫存」按鈕可以恢復上次手動儲存的編輯內容。若無暫存資料，「讀回暫存」按鈕將會禁用。

HackMD 整合

  • 開啟HackMD: 彈出檔案總管，列出你 HackMD 裡最近的筆記（按最後更新排序、可搜尋標題）。點選筆記會以其 Markdown 內容渲染成編輯區格式；開啟前會先確認是否暫存目前內容。
  • 存入HackMD: 若該分頁已從 HackMD 開啟過筆記，會直接更新原檔案（跳確認）；否則以「另存新檔」模式建立新筆記，並自動綁定該分頁。
  • API Token: 首次使用需填入你的 HackMD API Token（於 hackmd.io「設定 → API」建立）。勾選「在本機記住」後，Token 會儲存在瀏覽器本機，下次不用再貼。
  • 不支援的語法: 含有表格、程式碼塊、mermaid、數學式、圖片等語法的筆記在開啟時會示警並預設擋下（可手動強制開啟），避免存回時損毀這些區塊。
  • 分頁綁定: 三個編輯分頁可各自綁定不同的 HackMD 筆記（分頁鈕右上有小圓點標示）；重新整理頁面後綁定會解除，下次儲存會變成另存新檔。

多文件編輯

  • 點擊上方的 1, 2, 3 數字按鈕，可以在三個獨立的編輯區之間切換。
  • 每個編輯區都有各自獨立的內容與暫存功能，互不干擾。

模式切換

  • 點擊左上角 Logo: 可切換輸入法至「無效模式」或恢復上次使用的模式（嘸蝦米/英數），方便臨時停止輸入法功能。
