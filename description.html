功能說明

快捷鍵

  • 切換輸入法: Ctrl + p
  • 粗體: Ctrl + b　斜體: Ctrl + i
  • 標題 1/2/3: Ctrl + 1 / 2 / 3
  • 連結: Ctrl + k　清單: Ctrl + l
  • 程式碼塊: Ctrl + Shift + k　引用: Ctrl + Shift + q
  • 預覽/回編輯（Markdown 渲染）: Ctrl + Shift + m
  • 放大編輯區整體字級: Ctrl + ], Ctrl + Shift + >, 或 Ctrl + 0
  • 縮小編輯區整體字級: Ctrl + [, Ctrl + Shift + <, 或 Ctrl + 9
  • 存入 HackMD: Ctrl + s

編輯模式與匯出

編輯區為 Markdown 源碼模式：你看到的就是 # 標題、**粗體** 這般的原始語法（附語法高亮）。按 Ctrl + Shift + m 進入整頁預覽，表格、程式碼、數學式（KaTeX）、mermaid 圖表都會完整渲染；再按一次回編輯。

點擊「匯出」下載的就是編輯區裡的 Markdown 原始檔；「複製」同理複製源碼文字。

自動存稿

  • 編輯內容會自動存入瀏覽器（輸入後約半秒、切換分頁、或離開頁面時立即保存），重新開啟頁面即自動載回，不必再按任何按鈕。
  • 每個分頁（1/2/3）各自獨立保存。

HackMD 整合

  • 開啟HackMD: 彈出檔案總管，列出你 HackMD 裡最近的筆記（按最後更新排序、可搜尋標題）。點選筆記會以 Markdown 原始源碼 載入編輯區（內容一字不改）；編輯區已有內容時會先請你確認。
  • 存入HackMD: 若該分頁已從 HackMD 開啟過筆記，會直接更新原檔案（跳確認）；否則以「另存新檔」模式建立新筆記，並自動綁定該分頁。
  • API Token: 首次使用需填入你的 HackMD API Token（於 hackmd.io「設定 → API」建立）。勾選「在本機記住」後，Token 會儲存在瀏覽器本機，下次不用再貼。
  • HackMD 特殊語法: 源碼模式下編輯與存回都不會損毀任何語法；若筆記含有本站預覽無法呈現的 HackMD 專屬語法（如 container），開啟時會提示知悉。
  • 分頁綁定: 三個編輯分頁可各自綁定不同的 HackMD 筆記（分頁鈕右上有小圓點標示）；重新整理頁面後綁定會解除，下次儲存會變成另存新檔。

多文件編輯

  • 點擊上方的 1, 2, 3 數字按鈕，可以在三個獨立的編輯區之間切換。
  • 每個編輯區都有各自獨立的內容、游標位置與自動存稿，互不干擾。

模式切換

  • 點擊左上角 Logo: 可切換輸入法至「無效模式」或恢復上次使用的模式（嘸蝦米/英數），方便臨時停止輸入法功能。
